ประกาศความเป็นส่วนตัว

ปรับปรุงล่าสุด: 19 ตุลาคม 2569

เราคือใคร

บริษัท ลี โซลูชันส์ แอนด์ คอนซัลติ้ง จำกัด ("เรา") รับผิดชอบต่อข้อมูลส่วนบุคคลที่อธิบายไว้ในที่นี้ ติดต่อเราได้ที่ info@leesc.in ที่อยู่จดทะเบียน: กรุงเทพฯ ประเทศไทย

เว็บไซต์นี้เก็บข้อมูลอะไรบ้าง

  • แบบฟอร์มติดต่อ แบบฟอร์มบนหน้าแรกไม่ได้ส่งข้อมูลด้วยตัวเอง แต่จะเปิดโปรแกรมอีเมลของคุณพร้อมข้อความที่พร้อมส่ง เราจะได้รับชื่อ อีเมล บริษัท หัวข้อ และข้อความของคุณก็ต่อเมื่อคุณกดส่งในโปรแกรมอีเมลของคุณเท่านั้น
  • อีเมลที่คุณส่งถึงเรา หากคุณอีเมลถึงเราโดยตรง เราจะได้รับที่อยู่อีเมลของคุณและข้อความที่คุณเขียน
  • คุกกี้และการติดตาม เราแบ่งคุกกี้เป็นสามหมวดหมู่ หมวดจำเป็นเปิดตลอด ใช้จดจำภาษาและตัวเลือกคุกกี้ของคุณในเบราว์เซอร์ของคุณเอง และไม่ใช้เพื่อติดตาม หมวดวิเคราะห์เป็นทางเลือก เราใช้ Google Analytics เฉพาะเมื่อคุณอนุญาตเท่านั้น โดยตั้งค่าคุกกี้เพื่อนับจำนวนผู้เข้าชม หน้าที่เปิดดู และการคลิกลิงก์อีเมลและ LINE ของเรา Google ได้รับข้อมูลการเข้าชมและที่อยู่ IP (ย่อ) เพื่อวัตถุประสงค์นี้ และอาจประมวลผลนอกประเทศไทย หมวดการตลาดเป็นทางเลือกและขณะนี้ยังไม่ได้ใช้ เราไม่ใช้เครื่องมือโฆษณา หมวดที่เป็นทางเลือกจะปิดไว้ก่อน จะไม่มีการโหลดสิ่งใดจนกว่าคุณจะอนุญาต (ยอมรับทั้งหมด หรือเลือกตามหมวดหมู่ด้วยปุ่มปรับแต่ง) และคุณเปลี่ยนการเลือกได้ทุกเมื่อ:
  • การเลือกภาษา ปุ่มเปลี่ยนภาษาไทย / อังกฤษจะบันทึกการเลือกของคุณไว้เฉพาะในเบราว์เซอร์ของคุณบนอุปกรณ์ของคุณเท่านั้น เราไม่ได้รับข้อมูลนี้
  • บันทึกการโฮสต์ เว็บไซต์นี้โฮสต์บน GitHub Pages GitHub บันทึกหมายเลข IP ของผู้เยี่ยมชมเพื่อวัตถุประสงค์ด้านความปลอดภัย (ดู คำอธิบายของ GitHub)

เราใช้ข้อมูลของคุณเพื่ออะไร

เราใช้ข้อมูลเพื่อตอบคำถามของคุณ เพื่อพูดคุยและให้บริการหากคุณกลายเป็นลูกค้า และเพื่อเก็บบันทึกทางธุรกิจตามปกติ

เราเก็บข้อมูลนานเท่าใด

เราเก็บอีเมลสอบถามไว้นานเท่าที่จำเป็นเพื่อดำเนินการตามคำขอของคุณและสำหรับบันทึกทางธุรกิจ แล้วจึงลบออก

สิทธิของคุณ

คุณสามารถขอทราบว่าเรามีข้อมูลส่วนบุคคลใดเกี่ยวกับคุณ และขอให้แก้ไขหรือลบข้อมูลดังกล่าวได้ ตามที่พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562 ของประเทศไทยอนุญาต ส่งอีเมลถึงเราที่ info@leesc.in
